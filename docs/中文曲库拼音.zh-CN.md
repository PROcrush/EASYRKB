# EASYRKB 中文曲库搜索

- 原始中文曲名、表演者可直接搜索。
- 全拼：七里香 → `qilixiang` 或 `qi li xiang`。
- 首字母：七里香 → `qlx`，周杰伦 → `zjl`。
- 组合：`zjl qlx` 同时匹配表演者与曲名；曲名/表演者搜索范围也支持对应别名。
- `ü` 可用 `v` 输入，例如女儿情 → `nverqing`；英文 DJ、Remix、Live 和数字保留。

曲库加载、导入或名称修改时生成索引，输入搜索词时直接查询缓存，不联网转写。内置单字字典和 47,111 条词组读音，最长词组优先。多音字、艺名可手动修正。

“设置 → 中文曲库 → 为全库生成拼音”可重新生成整个曲库的索引。右键曲目选择“为所选曲目生成拼音”，或“修正读音”。修正时用空格分隔音节，字段留空使用自动读音，也可点击“恢复自动读音”。批量生成显示进度和处理数量，重复执行不会累加到标题中。

手动读音按曲库和原始名称保存在本机，重启、重新加载、重新生成均保留；名称改变时自动使用新名称的读音。开启资料库保护或 rekordbox 正在运行时仍可使用，因为不修改 rekordbox 数据库、音频标签或原文件。

此功能适用于 EASYRKB 本地曲库搜索。导出到 U 盘的原始字段保持原样，CDJ 上的拼音搜索需另行处理。
