# NCM 格式转换

在主窗口顶部点击 **NCM 格式转换**，可直接转换电脑上的网易云音乐 `.ncm` 文件。

1. 点击 **添加 NCM 文件**，可一次选择多个文件。
2. 点击 **选择输出文件夹**，指定音频保存位置。
3. 点击 **开始转换**，在列表查看每个文件的结果。
4. 完成后点击 **打开输出文件夹**，可将其中的 MP3 或 FLAC 文件通过软件原有的文件导入功能加入曲库。

转换在本机完成，不上传文件，也不需要额外安装转换程序。输出格式根据原始音频自动识别，不重新编码、不改变音质。原 NCM 文件保留，已有输出文件不会被覆盖，同名文件自动添加 `(1)`、`(2)` 等编号。

单个文件转换失败不会中断其余文件。点击 **重试未完成文件** 只处理失败或尚未开始的文件；已成功的文件不会重复转换。**当前文件完成后停止** 会保存正在处理的完整文件，然后停止队列；转换期间关闭按钮与 Escape 暂时不可用。

本功能支持含 MP3 或 FLAC 音频的标准 NCM 容器。输出保留原文件名和音频内已有的标签，NCM 单独保存的曲目信息、封面和歌词暂不补写。其他加密格式不在此功能范围内。

实现使用 RustCrypto AES，在固定大小的缓冲区中还原音频；完整写入临时文件后再以不覆盖方式发布结果。格式结构参考 [ncmdump.rs](https://github.com/iqiziqi/ncmdump.rs)。
