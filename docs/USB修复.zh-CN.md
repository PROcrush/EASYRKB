# EASYRKB U 盘修复使用说明

本功能包含在 EASYRKB 桌面版中。请从本项目 Releases 下载当前版本，安装后默认读取本机曲库。

## 入口

- 设置 → 优先选项 → USB 导出 → 打开 U 盘诊断与修复…
- 设备 → 右键 U 盘 → U 盘诊断与修复…

## 诊断缓存

在“设置 → USB 导出”或诊断窗口中选择“单次诊断缓存上限”。默认 8 GiB，可选 1、2、4、8、16、32、64 GiB；它限制每次诊断复制到电脑上的数据库、分析文件和封面快照，不限制曲目数量。修改后重新诊断即可生效，实际占用会显示在页面上。

“清除诊断缓存”先确认，再删除本机诊断快照和报告。保留 U 盘内容和修复前备份。正在诊断、读取预览或执行修复时禁止清理；清理会使所有窗口中的旧预览失效，必须重新诊断。

## 修复当前 U 盘

1. 选择已连接的 U 盘，或选择包含 `PIONEER` / `.PIONEER` 的根目录。
2. 点击“开始只读诊断”。每个数据库独立检查，坏库不会阻止读取好库。
3. 选择正确的可读来源，核对曲目、播放列表、Cue、拍网及缺失音频。双库内容不同的时候，选择你希望保留的那一版。
4. 保持默认“修复当前 U 盘”，查看“将重建的数据库”。选 OneLibrary 会重建 PDB；选 PDB 会重建 OneLibrary。
5. 勾选核对项，点击“备份并修复当前 U 盘”。先在电脑上备份原数据库及其附属文件并校验 SHA-256，再在本机生成和验证修复库，最后写回并回读。
6. 结果页显示修复文件、备份目录和报告路径。数据库结构检查通过后，再用你的 DJ 播放器核验歌单、加载和播放。

音乐和分析文件保留在原位置，所选来源库不被替换。缺失音乐需要从备份恢复或重新定位；数据库修复无法重建丢失音频。重建库中无法读取的其他字段可能无法恢复，界面会说明当前保留范围。

## 其他输出

“恢复到新空 U 盘”会把可读曲目和分析文件复制到空目标，重建双库；缺失音乐跳过并报告。“导出恢复 XML”会保留缺失曲目的原路径，供 rekordbox 后续重新定位。

已有未完成写入日志时，原盘修复会停止并保留日志，可先选择新盘或 XML 输出。两份库都不可读时需要可读副本，本版没有深层数据库页扫描或物理 U 盘修复。

## 本机备份

原盘修复备份保存在应用数据目录下的 `usb-recovery/backups/EASYRKB-before-repair-*`，结果页给出实际路径。`backup.json` 记录来源、将修改的文件及各原文件哈希。备份未通过时不执行原盘替换。
